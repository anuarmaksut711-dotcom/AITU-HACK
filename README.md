# Aimeet — AI Meeting Intelligence

Локальное рабочее пространство для записей встреч и будущего AI-протоколирования. React + TypeScript, FastAPI, PostgreSQL, Docker Compose.

**Реализованы архив и локальное распознавание.** Доступ по паролю, серверные сессии, библиотека встреч, поиск, сохранение исходного текста, загрузка MP3/WAV/M4A, фоновая транскрибация Faster-Whisper с отменой и повтором, просмотр и удаление. Готовая стенограмма помечается отдельно от черновика. Добавлен канбан и локальный разбор встречи: выжимка, решения, поручения, темы, вопросы и риски; ручная проверка, CSV/JSON, печать/PDF и календарь ICS. Требуются миграция и отдельный intelligence-worker с локальным Ollama. [Настройка и границы проверок](docs/kanban.md).

## Запуск

```sh
# Для распознавания сначала подготовьте модель (см. docs/transcription.md).
make up
```

Откройте [127.0.0.1:8787](http://127.0.0.1:8787). Учётные данные создаются в локальном `.env`: `BOOTSTRAP_EMAIL` и `BOOTSTRAP_PASSWORD`. При повторном запуске существующие секреты и пользователь сохраняются. Для сборки нужны Docker Desktop / Engine с Compose v2, Python 3 и доступ к реестрам зависимостей.

```sh
make status  # состояние контейнеров
make logs    # логи API и web без текста встреч
make down    # остановка с сохранением данных
make backup  # резервная копия PostgreSQL
```

## Структура

```text
apps/
  web/                  React SPA: маршруты, формы, API-клиент, UI
  api/                  FastAPI: core, db, modules/auth, meetings, transcription, rag
packages/contracts/     OpenAPI — транспортный контракт
infra/docker/           Отдельные сборки frontend и backend
infra/nginx/            Same-origin reverse proxy и security headers
scripts/                Инициализация, backup/restore, API smoke
docs/                   Архитектура, эксплуатация и границы этапа
compose.yaml            web + api + PostgreSQL + one-shot миграции
```

Frontend спроектирован через Frontend Workbench с отдельным ImageGen-макетом для каждой страницы. Служебные макеты, проверки и состояние workflow находятся в игнорируемой `.frontend-workbench/`, отдельно от исходников продукта.

Элементы интерфейса построены на Mantine: поля, выбор языка и файлов, кнопки, навигация, статусы, уведомления, раскрываемые цитаты и диалог удаления. Общая тема задаётся в `apps/web/src/theme.ts`, расположение блоков — в `styles.css`. Новые контролы следует брать из `@mantine/core`. Текстовые формы используют React Hook Form, `Select` подключён через `Controller`; навигационные компоненты сохраняют семантику ссылок через `renderRoot`. CSP nonce передаётся провайдеру темы и блокировке прокрутки.

## Договорённости

- Один HTTP origin; cookie `HttpOnly`, `SameSite=Strict`, отзыв сессии на сервере.
- Встречи доступны только в workspace авторизованного пользователя.
- Миграции запускаются отдельно до API; данные PostgreSQL живут в именованном томе.
- API и база не публикуют host-порты; web слушает `127.0.0.1`. База подключена к internal-сети; API и RAG-worker в стандартном профиле имеют egress для OpenAI. Offline-overlay убирает их egress; web публикует интерфейс через edge-сеть.
- Исходный текст сохраняется дословно. RAG создаёт отдельные embeddings; передача текста в OpenAI явно показана в интерфейсе. В offline-профиле оба AI-провайдера локальные.
- Vexa — предусмотренная будущая интеграция захвата, по умолчанию отключена; загрузка файлов остаётся самостоятельным offline-сценарием.

Подробности: [архитектура](docs/architecture.md), [запуск и эксплуатация](docs/operations.md). Проверки кода не заменяют приёмку качества реальных моделей и режима без внешней сети.

## Распознавание аудио

Добавлена локальная транскрибация MP3/WAV/M4A через Faster-Whisper: загрузка, фоновая обработка, отмена/повтор и стенограмма с временными отметками. Перед первым запуском нужно подготовить веса модели. [Выбор движка, установка, ограничения и проверки](docs/transcription.md).
