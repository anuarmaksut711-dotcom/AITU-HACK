# Проверка реализации RAG

Дата: 2026-09-11. Проверки относятся к локальной реализации, а не к качеству реального GPT/Ollama.

- SQLite: `pytest tests` — 92 passed (включает существующие тесты доступа/встреч и параллельно добавленной транскрибации).
- PostgreSQL 17 + pgvector 0.8.6: `pytest tests` — 92 passed. Отдельный временный контейнер, отдельная случайная схема на тест, не рабочая база приложения.
- После дополнительной защиты от смены исходника во время ответа: RAG-набор (45 проверок) повторно прогнан на PostgreSQL.
- Миграции `0001 -> 0002 -> 0003`: применены в отдельной тестовой PostgreSQL. `alembic check`: `No new upgrade operations detected`. Откат `0003 -> 0002` и повторное применение также прошли.
- Исправлено повторное применение naming convention при удалении check constraints в миграции `0002`: использование `op.f` необходимо для успешного применения цепочки на PostgreSQL.
- OpenAI/Ollama/OpenAI-compatible: проверены запросы и обработка ответов через HTTP MockTransport. Облачные вызовы с платной генерацией не выполнялись; качество и latency реальных моделей не измерены.
- Граф: доказаны lossless offsets, повторяемые ID, сосед через границу parent, ограничения бюджета, дедупликация, версии исходника и embeddings, отсутствие смешивания встреч.
- Worker: проверены CAS-конкуренция, recovery после expiry, блокировка публикации старым worker, отсутствие частичного индекса при ошибке provider и retry failed.
- Ответ: проверены ссылки на существующие источники, дословное происхождение цитат, отсутствие генерации без источников, контролируемые ошибки вместо success при refusal/incomplete/malformed response.
- Frontend: `npm run lint` и `npm run build` прошли на актуальном Mantine-интерфейсе; OpenAPI/types синхронизированы.
- Браузер: отдельные API/Vite порты и синтетическая встреча, детерминированный provider только во временном тестовом harness. Подготовка через реальный worker, вопрос, ответ и раскрытие дословной цитаты проверены. Desktop/mobile 390px просмотрены; горизонтальный overflow = 0. Ошибка timeout показана понятным текстом, введённый вопрос сохранён. `insufficient_evidence` показан без выдуманного ответа.
- Compose: стандартный и offline overlay проверены `docker compose config --quiet` с несекретным env example. Стандартный профиль имеет AI egress, overlay заменяет сети API/RAG-worker на internal. Полный inference с подготовленной Ollama в отключённой сети не запускался.

Рабочие контейнеры и пользовательские данные этим прогоном не заменялись. Для эксплуатации нужен прогон выбранных реальных моделей на размеченном наборе RU/KK/EN и проверка offline-сети после загрузки весов.
